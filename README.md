## Purpose

This project demonstrates Python lists, NumPy arrays, and dictionaries
using fictional student information.

## Program features

- A list of student names and a NumPy array of those names.
- A list of ages and an array showing ages in two years.
- 2D and 3D arrays with edit, add, and delete operations.
- A dictionary containing each student's name, age, DOB, and location.

Student ages use 5 October 2026 as the reference date.

## Running the program on Windows

Install Python 3, then open a terminal inside the project folder.

Create a virtual environment:

```powershell
python -m venv venv-student
```

Install the required packages:

```powershell
.\venv-student\Scripts\python.exe -m pip install -r requirements.txt
```

Run the program:

```powershell
.\venv-student\Scripts\python.exe students.py
```
